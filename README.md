# ナンバーズ解析ツール (NUMBERS_ANALYZER)

> **🌐 ライブデプロイ (Web公開URL)**: [https://tk030-lotto.github.io/numbers-predictor-lite/](https://tk030-lotto.github.io/numbers-predictor-lite/)

過去の当選結果データに基づき、JavaScript による「構造解析5指標（ナンバーズ仕様）」を用いて出現確率の低い数字や組み合わせを「排除」し、期待値の高い組み合わせを厳選・分析する静的ウェブアプリケーションです。履歴データは GitHub Actions による日次自動更新で `numbers_data.js` に反映されます。

---

## 📁 機能概要

*   **予想（排除）**: ナンバーズ4／ナンバーズ3 の直近100回分の履歴データ（バンドル同梱）を用い、「構造解析5指標」（②合計値・①奇偶バランス・③同位置引っ張り・⑦同位置スライド±1・⑤隣接桁の連番）による多段フィルターと、位置別EMA期待値によるスコアリングで生存組み合わせを厳選し、上位5点を表示します。
    *   ②合計値 (S級): N4 推奨レンジ `18 〜 22` / N3 推奨レンジ `13 〜 16`
    *   各桁（千・百・十・一の位）の出現傾向を EMA（指数移動平均）で表示する「桁別合議排除ボード」。タップで数字の個別排除・復活が可能です。
    *   チェックボックスによる許可する奇偶構成・引っ張り桁数・スライド桁数・連番の要/不要の切替。
*   **検証バックテスト**: 現在のフィルター設定（手動排除を除く）で、過去の特定回数分を「その回の前回時点のデータのみで予想した」場合の捕捉率などをシミュレーションします。
*   **データ管理**: 履歴データは同梱の `numbers_data.js`。手動入力（1件追加／CSVコピペ）およびツール内の「最新結果を自動更新」ボタンでロトデータハブから最新データを取得し、localStorage にマージできます。
*   **利用前の同意**: 初回利用時に利用規約・免責事項への同意が必要です。

データの最新版は、GitHub Actions（`.github/workflows/data_updater.yml`）が `update_data.py` を実行して日次で `numbers_data.js` を更新します。一次ソースは `loto-life.net`、失敗時はバックアップとしてロトデータハブ（`lotto-data-hub`）を参照します。

## 🛠 技術構成

*   完全静的構成（HTML/CSS/Vanilla JS・ビルド不要・依存ライブラリなし）
*   ホスティング: GitHub Pages
*   履歴データ: `numbers_data.js`（`const DEFAULT_NUMBERS_DATA = ...`）
*   自動更新: `update_data.py`（Python、GitHub Actions から実行）

---

## 🔒 外部通信について

*   **アクセス解析**: Cloudflare Web Analytics（ページ閲覧の統計把握のため、閲覧情報が Cloudflare に送信されます）
*   **フォント**: Google Fonts（フォントファイル取得時に Google へ通信が発生します）
*   **データ取得**: 「最新結果を自動更新」ボタンを押した場合のみ、ロトデータハブ（`lotto-data-hub` の JSON）から最新の当選データを取得します
*   上記以外に、ツールが利用者の情報を外部へ送信する経路はありません
