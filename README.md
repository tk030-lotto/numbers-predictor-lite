# ナンバーズ解析ツール (NUMBERS_ANALYZER)

本プロジェクトは、過去の当選結果データを基に、JavaScriptによる「宝田式7指標（ナンバーズ仕様）」を用いて出現確率の低い数字や組み合わせを「排除」し、期待値の高い組み合わせを厳選・分析する静的ウェブアプリケーションです。

## 🔮 実装予定の「宝田式7指標」（ナンバーズ仕様）

聖典（各種情報フォルダの参照資料）に登録した最新の実測統計データに基づき、以下の指標と推奨設計手順をJavaScriptロジックに組み込む予定です。

### 1. 7指標の排除力と優先順位（N4/N3）

| 指標 | ランク | ナンバーズ4 (N4) 排除力 | ナンバーズ3 (N3) 排除力 | 役割・判定基準 |
| :--- | :---: | :---: | :---: | :--- |
| **②合計値** | **S** | **68.9%** | **70.9%** | 最強のフィルター。推奨範囲外を排除。<br>・N4推奨値: `18 〜 22`<br>・N3推奨値: `13 〜 16` |
| **③引っ張り** | **A** | **64.7%** | **72.3%** | 前回データ依存型。前回の各桁と同じ数字が残る桁を確定・評価。 |
| **①奇偶** | **A** | **61.6%** | **25.8%** | 奇数と偶数の比率。<br>・N4推奨: `2奇:2偶` (排除力61.6%を重視) |
| **⑤連番** | **A** | **55.3%** | **68.8%** | 隣接する桁に差1のペアがあるか確認。 |
| **⑦スライド** | **B** | **46.1%** | **55.0%** | 引っ張り以外の桁は前回値の ±1 を候補にする。 |

## 🚀 次回からの開発予定ステップ

1.  **データのインポート・管理機能**:
    *   ナンバーズ4・3の過去履歴データを格納する `numbers_data.js` 等の設計、および手動/コピペインポート機能の実装。
2.  **AI排除・解析ロジックの肉付け**:
    *   上記7指標に基づいて、各桁（0〜9）または組み合わせ全体の「排除期待スコア」を計算し、合議判定するロジックの実装。
3.  **厳選予想の生成アルゴリズム**:
    *   生存プールから、S→A→Bの推奨順に合格した組み合わせを抽出し、厳選予想（5点など）を提示する。
